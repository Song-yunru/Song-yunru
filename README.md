### 🍓 Auto Reset

A plugin for [AstrBot](https://github.com/AstrBotDevs/AstrBot) that runs `/reset` automatically every *N* days at a chosen time, clearing the LLM conversation context so the bot's memory never grows forever.

[![Repo](https://img.shields.io/badge/repo-astrbot__plugin__auto__reset-e0457d?style=flat-square&logo=github&logoColor=white)](https://github.com/Song-yunru/astrbot_plugin_auto_reset)
[![Release](https://img.shields.io/badge/release-v1.0.0-f7a8c4?style=flat-square&logo=github&logoColor=white)](https://github.com/Song-yunru/astrbot_plugin_auto_reset/releases/tag/v1.0.0)

</td>
<td width="50%" valign="top">

### ⏰ Scheduled @ Mention

A plugin for [AstrBot](https://github.com/AstrBotDevs/AstrBot) that @-mentions chosen members in group chats at a **fixed time** or a **random time window**, with editable message contents.

[![Repo](https://img.shields.io/badge/repo-astrbot__plugin__scheduled__at-e0457d?style=flat-square&logo=github&logoColor=white)](https://github.com/Song-yunru/astrbot_plugin_scheduled_at)
[![Release](https://img.shields.io/badge/release-v1.0.0-f7a8c4?style=flat-square&logo=github&logoColor=white)](https://github.com/Song-yunru/astrbot_plugin_scheduled_at/releases/tag/v1.0.0)
